Materials & Tech

What you need to have ready, and the class resources you’ll use all semester.

  • A laptop that can run VS Code and, later, Xcode (Mac) or Visual Studio (Windows) for openFrameworks.
  • p5.js (web editor, then local/VS Code template) for Weeks 1–7.
  • openFrameworks plus a C++ toolchain for Weeks 8–14.
  • A GitHub account. GitHub Pages hosts every weekly submission, all semester.
  • A YouTube, Vimeo, or SoundCloud account for the Week 14 Digital Expo portfolio.
  • Class examples: CodingArtFundamentals-ClassExamples on GitHub.
  • Sine and Cosine Interactive Visualization — Week 5 prep, how a point going around the unit circle traces out sine and cosine.
