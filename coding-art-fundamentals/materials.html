Coding Art Fundamentals · Materials

Materials & Tech

What you need to have ready, and the class resources you’ll use all semester.

Students need a laptop capable of running both the p5.js web editor, which works in any modern browser, and, from Week 8 onward, openFrameworks, which requires a Mac or Windows laptop able to compile C++ and run Xcode or Visual Studio. No computer lab is available this semester, so this must be a student’s own machine.

Software used over the semester

  • A modern web browser, for the p5.js web editor
  • VS Code
  • A GitHub account, used for weekly submissions from Week 2 on, via GitHub Pages
  • Xcode (Mac) or Visual Studio (Windows), required to compile C++ for openFrameworks
  • openFrameworks (free), installed from a pre-recorded walkthrough assigned as homework before Week 8

Canvas is used for all weekly assignment instructions. No textbook purchase is required.

A pre-recorded walkthrough of how to submit through GitHub Pages lives in Canvas, linked from every assignment.

Class resources

  • Class examples: CodingArtFundamentals-ClassExamples on GitHub.
  • openFrameworks starter template: OF_Starter-Template on GitHub.
  • Sine and Cosine Interactive Visualization — Week 5 prep, how a point going around the unit circle traces out sine and cosine.
