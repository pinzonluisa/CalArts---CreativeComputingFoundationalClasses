Weekly Schedule

Weeks 1–14, moving from p5.js to openFrameworks and C++. Each week below is a short version; full assignment instructions, with step by step detail, are posted in Canvas.

Deadlines

Each weekly assignment is due by 11:59 PM one week after it’s assigned, the same day as the following class. Late work is accepted only under specific circumstances, considered case by case. See Policies.

Week 10 (Nov 11) is pre-recorded instead of in person, for a campus holiday.

01Sept 9p5.js

Foundations and First Code

In Class

  • Course introduction, expectations, and course load.
  • A short live demo on why fundamentals matter before leaning on AI tools: solving a short sequence of arithmetic problems by hand, starting simple (two-digit addition) and getting harder each time (multi-digit multiplication, then a multi-step order-of-operations problem with parentheses and division), then handing that last problem to an AI tool and watching it solve it live, sometimes correctly, sometimes with a wrong step buried in the middle. The point: a student who worked through the problem by hand can immediately catch the AI’s mistake; a student who skipped straight to the AI has no way to know it’s wrong.
  • First code in the p5.js web editor (editor.p5js.org): creating an account and saving a sketch.
  • What syntax is, and how it changes across languages.
  • Cartesian coordinates (x, y) and basic shapes, using the p5.js reference library.
  • Shape parameters: position, size, and color.
  • The setup() and draw() functions, without movement yet, and why line order matters.

Assignment Overview

  • Watch a short beginner video series on the p5.js workspace.
  • Build two or more colored shapes in the p5.js editor.
  • Research one artist working in interactive or real time digital art, and submit a short write-up with a link.
  • Install VS Code with the p5.js extensions.

05Oct 7p5.js

The Bouncing Ball: Functions

In Class

  • Introduction to functions: the bouncing ball refactored into functions, including a random color change triggered on each bounce.
  • Sine, with cosine introduced as an alternative, explained for oscillation, first mapped directly to shape size and color, then refactored into a reusable return function.
  • Loops and functions combined to draw multiple layered shapes offset by the sine wave, ending with a mouse interactive color inversion example.

Assignment Overview

  • Based on the code used in class (class code repository), create a piece using functions.
  • Use the class exercises as a starting point to develop your own piece, making sure to use functions, along with sine or cosine for motion or color.
  • Feel free to explore the p5.js library to push further than what was covered in class.

08Oct 28oF / C++

Intro to C++ and openFrameworks

In Class

  • Introduction to C++ and the openFrameworks project generator.
  • The Week 6 bouncing ball exercise rebuilt in C++: same logic, new syntax.
  • C++ arrays have a fixed size, so this is also where std::vector comes in: C++’s adjustable size container, and the equivalent of the resizable arrays used in JavaScript.

Assignment Overview

  • Based on the code used in class (class code repository), create a piece in C++ and openFrameworks.
  • Use the class exercises as a starting point to develop your own piece, making sure to use the openFrameworks setup()/update()/draw() structure.
  • If your piece used a resizable array in JavaScript, convert it into a C++ std::vector, since plain C++ arrays can’t grow or shrink the way JavaScript arrays can.
  • Feel free to explore openFrameworks further than what was covered in class.
  • Submission is the same process as before, minus the GitHub Pages portion: openFrameworks doesn’t run in the browser, so this week just means uploading your project to the class repository on GitHub.
