Coding Art Fundamentals · Schedule

Weekly Schedule

Weeks 1–14, moving from p5.js to openFrameworks and C++. Three weeks are shared across all three Fall 2026 Creative Computing courses.

Weekly homework, in one line

Every class is recorded, and that recording is always available as a reference. Each week’s assignment is posted in Canvas — sometimes it’s reproducing what we did in class plus adding something, sometimes it’s your own exploration, and sometimes there are specific instructions. Always check Canvas for that week’s assignment. Due 11:59 PM one week after it’s assigned, the same day as the following class. Late work is accepted only under specific circumstances, considered case by case. See Policies.

Final project: identical structure and deadlines to Coding Music Fundamentals and Intro to TouchDesigner. See Final Project.

Standing assignment · given Week 1

Read the Vectors and Noise chapters of The Nature of Code, or watch the equivalent Coding Train video series. Do this at your own pace, but the Vectors material needs to be done by Week 9 and the Noise material by Week 11. Each of those weeks has a short in-class quiz checking basic understanding, not coding fluency.

01Sept 9p5.js

Foundations Review

  • Opening the p5.js web editor together in class for this first session, not VS Code — VS Code still gets installed today, just not used yet.
  • A simple instructor example first, then the class types a few things together in p5.js, live.

Assignment: watch this short, beginner-friendly series on creative coding, then build a first p5.js sketch — a shape, placed at a position, given an RGB color, moved with sine/cosine. Copy-pasting the code shown in the videos is completely fine here — the goal is refreshing the vocabulary (coordinates, RGB, sine/cos) and getting some initial hands-on coding in, not understanding concepts like variables yet (that comes later). Submit as a p5.js web editor sketch link, submission mechanics shown live in class.
