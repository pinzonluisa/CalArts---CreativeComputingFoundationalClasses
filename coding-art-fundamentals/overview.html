Overview

Course Description

Coding Art Fundamentals sits at the intersection of computer science, digital graphics, and creative expression. The course is built for beginners and introduces foundational programming concepts through visual art, motion design, and interactive media.

Code is treated here as a creative medium, not strictly as an engineering tool. The course draws on a long history of creative coding environments, from early tools such as Lingo to foundational texts like Daniel Shiffman’s The Nature of Code, and uses that history to build a flexible way of thinking about programming, one that transfers to any language or environment a student picks up afterward.

The course divides into two halves, moving from core programming logic to a more advanced, performance oriented creative toolkit. All class code examples live in the class code repository.

Weeks 1–7 · p5.js

Core programming logic taught in p5.js: variables, conditionals, loops, functions, arrays, and classes, plus visual math (coordinates, trigonometry, color theory), ending in the midterm.

→
Weeks 8–14 · openFrameworks / C++

The same ideas again, in a compiled, strongly typed C++ environment, based on the first two chapters of Daniel Shiffman’s The Nature of Code: Perlin noise, vector math, and real time performance.

Midterm Project. This is where the first half’s skills come together. Each student creates their own challenge: developing a story, building something they personally resonate with, at any level. The goal is to create something, simple or not, that the student is proud of and enjoys, built in a way that requires solving their own problems to reach their own goal. See the Midterm Project page for details.

Final Project. The final project is done in groups, intentionally. Collaboration and co-creation are a core part of any art practice, and working in a group also builds skills every professional needs: communicating clearly, solving problems together, asking for help, and reaching decisions as a team. See the Final Project page for details.

Portfolio. A GitHub Pages link for each weekly sketch builds a public, web accessible portfolio of working code, not files on a hard drive. The final project adds a digital recording of the performance as part of that same portfolio.

Future pathways

The logic and mathematical foundations built in this course carry directly into later specializations, including:

  • Game design and development
  • 3D modeling and procedural systems
  • Physical computing, interactive installations, and robotics
  • Data visualization and generative art
How work gets in

Submission Model

Every weekly assignment is submitted as a live GitHub Pages link hosting that week’s sketch, not just a committed repo. This gets set up together in class in Week 2, then is treated as understood for the rest of the semester. Week 1 is the one exception: that first assignment is a p5.js web editor sketch link instead, submitted before GitHub Pages exists yet — submission mechanics get shown live in class.

By the end of the semester

Learning Outcomes

  • Work across two languages. Write and debug programs in both JavaScript (p5.js) and C++ (openFrameworks), using variables, conditionals, loops, arrays, functions, and classes.
  • Apply core creative coding techniques. Randomness, vector math, and noise, to build an original interactive visual sketch.
  • Publish interactive work to the web. Build and host a working project with GitHub and GitHub Pages.
  • Connect to other software. Link a program to at least one other piece of software, using a protocol such as OSC.

Masters students additionally build toward original tools or techniques beyond what’s covered in class, and a leading technical role in the required group final.

Credit Load

Credit Load

This is a 3-credit course, following CalArts’ standard credit-hour policy: 45 hours of work per credit for BFA students, 60 hours per credit for Masters students. That comes to 135 total hours for BFA students and 180 for Masters students across the semester. In-class time adds up to about 25.7 hours over the semester. The rest is independent work: roughly 7.8 hours a week for BFA students, and roughly 11 hours a week for Masters students.
