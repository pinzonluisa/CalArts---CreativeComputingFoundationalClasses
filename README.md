# CalArts — Creative Computing Foundational Classes

Three courses, three languages — sound, image, and real-time visuals — taught in parallel on the same weekly rhythm, then made to talk to each other in one shared final performance.

CalArts, Fall 2026. Instructor: Luisa Pinzon.

- **Coding Music Fundamentals** (ChucK)
- **Coding Art Fundamentals** (p5.js, then openFrameworks/C++)
- **Intro to TouchDesigner**

## Site

A simple static GitHub Pages site: one hub page (`index.html`) linking out to each course's own page. No build step, no framework — plain HTML/CSS, self-contained.

Once GitHub Pages is turned on for this repo (Settings → Pages → Deploy from branch `main`, root), it'll be live at:

`https://pinzonluisa.github.io/CalArts---CreativeComputingFoundationalClasses/`
