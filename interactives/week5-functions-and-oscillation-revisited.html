Week 5 · Oct 7p5.js · JavaScript

Functions

A function is a named, reusable block of code. Once it is declared, it can be called as many times as needed, each time with different parameters, the values passed in to change what it does.

Using a function always happens in two separate stages. Declaring it is writing out what it does, its name, and anything it needs, nothing runs yet at that point. Calling it is the separate line elsewhere in the sketch where it actually executes.

A void function performs an action and does not hand anything back, it runs on its own line. keepInCanvas() and randomColor() in this week's class examples are both void: they change global variables directly instead of returning a value. A function that returns a value computes something and hands it back to wherever it was called, so the result can be stored in a variable or used directly in an expression.

Local and Global Scope

A variable declared inside a function only exists inside that function, its local scope. A variable declared outside any function is global, and can be read or changed from anywhere in the sketch.

Harmonic Motion: Sine and Cosine

This week also returns to the sine and cosine motion from Week 3, this time starting from where it actually comes from: a point moving around a circle. As that point travels around the circle, its vertical position traces out sine and its horizontal position traces out cosine, together they form simple harmonic motion. The interactive diagram linked in Resources below works through this stage by stage, from the circle to the unrolled wave, before any of it goes into code.

Inverting Color

RGB color is made of three channel values: red, green, and blue, each ranging from 0 to 255. To invert a color, subtract each channel from 255. Take (20, 100, 100): the inverted version is (255 − 20, 255 − 100, 255 − 100), which comes out to (235, 155, 155).

This math flips each channel across the midpoint of the 0 to 255 range, 127.5. That is why it is called a negative, not a complementary color. A true complementary color comes from rotating the hue, not from this kind of channel math.

You can see this logic applied in class example 6, Loops Function Invert, on GitHub.

RGB and Hue

RGB and hue describe color in different ways. RGB breaks a color into three channel values: red, green, and blue. Hue describes a color as a single angle on a wheel, from 0 to 360 degrees. Screens actually emit light in RGB, but hue is standardized, so a color's hue angle comes out the same in p5.js, CSS, Photoshop, and TouchDesigner.

I am not going to dive into hue right now, so we do not take on more than we need this week, but I encourage you to start exploring color decisions as the midterm approaches. p5.js has its own hue() function worth experimenting with.
